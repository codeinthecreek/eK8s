# lineage/

A run's record on disk (DESIGN.md sec 5, sec 14): the genome archive (wrapper files plus a sha256), one JSONL attempt record per generation attempt, one JSONL stall-count line per (loadgen run, target) in `stalls.jsonl` (recording only; nothing in the run reads it), the raw `claude -p` transcripts, and under `cni/` calico-node's log per Stage 5 burst, per window and per window fault (`<name>.log`, capped at 1 MiB with a cut marker line, or `<name>.failed` for a failed read; recording only). For the first run the structured table is JSONL, not SQLite (docs/decisions.md, PR #52 S2 and PR #55); see `doc.go` for the layout and the rules.
